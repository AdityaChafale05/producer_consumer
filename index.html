Protected version

“Prepare next” uses a single atomic queue operation in this simulation, so one order is removed once.

Lab note: This is a front-end simulation. It models semaphore rules and race-condition outcomes for learning; JavaScript UI actions run on one browser event loop, so this is not a real multithreaded OS process or a multi-device ordering backend.
